# 手工冒烟测试清单

> **用途**：发布 / 大幅改动前，手动过一遍 UI 关键路径，快速暴露「能编译但跑起来就坏」的问题。
> 与自动化分层互补：T1/T2 管单元与集成，本清单管 T4 的人工 E2E 冒烟。
>
> **前置**：已按 `docs/构建与运行.md` 构建出 `agent_.exe`（命令行跑需先把 Qt/MinGW/ElaWidgetTools 加进 PATH）；准备一个有效的 API key。

每项在运行结果符合「预期」后打勾；不符合即记下现象，属冒烟失败。

---

## 1. 启动

- [ ] 双击 `agent_.exe`，主窗口正常弹出，无崩溃 / 无报错弹窗。
- [ ] 侧边栏导航正常：聊天 / 设置 / 关于 三个页面可切换。
- [ ] 任务栏图标出现；托盘区出现「Azur Agent」图标（tooltip 显示「企业等候您的指令」）。
- [ ] `daily_log/azur_debug_当天日期.log` 已生成且有内容（说明 qDebug 重定向正常）。

## 2. 设置页 · API 配置

- [ ] 设置页打开后，API Key / Base URL / 模型 显示的是上次保存的值（或首次的默认值）。
- [ ] 模型下拉框有「最近使用」历史建议（如果之前用过多个模型）。
- [ ] 填好有效 API key + base URL + 模型后，点「连接测试」→ 提示成功（失败时提示信息清晰，不崩溃）。
- [ ] 关闭应用再打开，API Key / Base URL / 模型 仍保留（QSettings 持久化）。

## 3. 聊天 · 发消息与流式回复

- [ ] 在聊天框输入文字，回车或点发送 → 开始请求，「企业」回复逐字流式出现（光标在侧边栏 / 底部有请求状态反馈）。
- [ ] 回复完成后显示完整内容，且**多轮对话**上下文连续（第二问能回答第一问的内容）。
- [ ] 发送后立刻再发一条，不会出现界面卡死（有等待态防护）。
- [ ] 网络断开 / key 无效时，错误信息以可见方式呈现（消息条 / 聊天区），不崩溃。

## 4. 新建 / 切换会话

- [ ] 「新建会话」→ 对话历史清空，重新开场。
- [ ] 「会话列表」能回到之前的会话，历史消息完整还原。
- [ ] 会话之间互不串扰（A 会话的上下文不污染 B）。

## 5. 语气一致性（P1）

- [ ] 设置页切换「完整人格 / 精简人格」后，回复语气有明显区别（完整更沉稳、军人式）。
- [ ] 连续聊 10+ 轮后，「企业」仍保持人设：不崩人设、不冒出与设定冲突的措辞。
- [ ] 被挑衅 / 越界话题时，回复保持克制，不骂人、不软萌化。

## 6. 事实记忆（P3）

- [ ] 设置页勾选「事实记忆」（默认关）→ 重启应用后仍保持勾选。
- [ ] 对话中告诉企业「我叫小明 / 喜欢龙井」，收到回复后等 2~3 秒（异步抽取），检查：
  `%APPDATA%/<AppName>/memory/facts.json` 出现 `user_name` / `preference_tea` 条目。
- [ ] 再次对话时，「企业」能回忆起上述事实（注入生效）。
- [ ] 同 key 新值会覆盖旧值；`memory/backups/` 有备份文件（写盘前备份）。

## 7. 语音朗读（P2）

- [ ] 设置页勾选「语音朗读」、选一个中文音色，点「试听」→ 能听到合成语音。
- [ ] 发消息收到回复后，自动合成并播放该回复的 mp3（无静音、无重复播放）。
- [ ] 播放中再发一条新消息 → 旧语音停止，不重叠。
- [ ] 未装 edge-tts / 断网时：不弹窗、不崩溃，仅 `daily_log` 里有失败日志（软件整体不受影响）。

## 8. 托盘与全局快捷键

- [ ] 点主窗口「关闭」→ 窗口隐藏而非退出；托盘图标仍在。
- [ ] 托盘右键菜单：显示 / 隐藏 / 退出 三项可用。
- [ ] 点击托盘图标（单击/双击）→ 窗口显示并前置。
- [ ] 窗口隐藏时按 `Ctrl+Alt+Q` → 窗口显示并前置。
- [ ] 托盘「退出」→ 进程完全结束（任务管理器无残留 `agent_.exe`）。

## 9. 工具调用（可选）

- [ ] 设置页配置了工作区根目录时，对话中让企业读取该目录内文件 → 能返回文件内容。
- [ ] 尝试访问根目录之外（`../` 越界）→ 被安全拒绝（返回错误，不越权）。
- [ ] 未配置工作区时，工具调用不启用（不误报）。

## 10. 设置持久化 / 主题

- [ ] 修改主题（浅色 / 深色 / 跟随系统）→ 界面即时切换；重启后保持。
- [ ] 修改聊天背景透明度 / 开启背景图 → 生效；重启后保持。
- [ ] 修改状态栏可见性 → 生效；重启后保持。
- [ ] 首次运行（清空配置）→ 各项都有合理默认值，不报错。
