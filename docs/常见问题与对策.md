## 常见问题与对策

按"症状"找文件，而不是按"文件名"找症状。

| 症状 / 需求 | 去哪个文件 |
|---|---|
| AI 回复不显示 / 流式输出卡住 | `ai_client.cpp`（SSE 解析）→ `agent_engine.cpp`（`onChunkReceived`）→ `chatpagewidget.cpp` 的 `onChunkReceived` |
| AI 调用工具没反应 / 工具报错 | `tool_executor.cpp`（`readFile`/`listDirectory`）→ 看 `execute()` 里的路由。先确认**设置页「对话设置 → 工作区目录」选了一个有效目录**——`mainwindow.cpp` 的 `onSendClicked()` 只有目录非空且存在时才把 `ToolExecutor::toolDefinitions()` 传给 `AgentEngine::start()`，没选目录工具定义就是空数组，AI 永远不会发起工具调用 |
| 企业想读文件但提示「工作区目录不存在」 | 工具只读权限沙箱在 `resolveSafePath()`：目标必须落在 `AppSettings::workspaceRoot()`（设置页选的目录）之内，越权访问直接拒绝。重新选一个目录即可 |
| 工具报「Python 工具后端不可用」或日志出现「回退原生实现」 | `tool_executor.cpp` 的 `executeViaPython()`。常见原因：项目根没有 `azur_agent/` 虚拟环境、`python/azur_tools/cli.py` 被移动/删除、进程启动超时。见「关键设计决策 → 7」。想确认走没走 Python，看日志里有没有 `[TOOL_EXEC]` 相关输出 |
| 工具报「Python 工具后端返回了无法解析的响应」 | 这是 Windows 编码坑：Python 写 stdout 用了 GBK 而不是 UTF-8。检查 `python/azur_tools/cli.py` 顶部 `sys.stdin/stdout.reconfigure(encoding="utf-8")` 是否还在，见「关键设计决策 → 7」 |
| 想跑 Python 侧工具测试 | 激活 `azur_agent` 虚拟环境后执行 `python python/azur_tools/tests/test_executor.py` |
| 想跑 C++ 单元测试（含 Python 后端集成测试） | 构建时打开 `AZUR_BUILD_TESTS=ON`，构建 `azur_agent_tests` 目标并运行，见「构建与运行 → 构建单元测试」 |
| 想加一个新工具 | `tool_executor.h/.cpp`：`toolDefinitions()` 加 schema → 写执行函数 → `execute()` 注册路由。如果新工具涉及写操作，需要重新设计确认机制（这部分连同 `previewDiff`/`isBlacklistedCommand`/`ConfirmDialogs` 已经整体移除，等于要从头搭） |
| 想加一个新的设置项 | `appsettings.h/.cpp` 加一对读写函数，**不要**在别处直接 `new QSettings` |
| 设置页某个选项选了没反应 | 先看 `appsettings.cpp` 里有没有对应的读函数真的被别处调用了 |
| 对话变长后企业崩人设 / 语气漂移 | 语气约束在 `app/resources/full|lite/enterprise_instructions.md`（P1），`agent_engine.cpp` 的 `sendRequest()` 组装好消息列表后注入（云端=尾部 system 消息，本地=拼到最后一条 user 消息）。想改语气风格改指令文件；想验证注入是否生效看 `test_agent_engine.cpp` 那两组注入测试。注意：改了指令文件后要重新构建（qrc 兜底把文件打进二进制），开发时走源码树路径则重启即可 |
| 语音朗读没声音 / 日志出现 TTS 合成失败 | `core/ttsclient.cpp`（QProcess 异步调 `tts_cli.py`）→ `python/azur_tools/tts_cli.py` → edge-tts。常见原因：没装 edge-tts（`azur_agent/Scripts/python.exe -m pip install edge-tts`）、没联网（edge-tts 在线合成）、设置的音色 ID 不存在。失败只 `qWarning` 不弹窗，看 `daily_log/` 里的日志 |
| 语音朗读太吵 / 想临时关掉 | 设置页「语音朗读」卡片取消勾选，或在 `mainwindow.cpp` 里删掉 `onApiResponseCompleted` 末尾那段 `tts_->synthesize(...)` 调用 |
| 想换企业说话的音色 | 设置页「语音朗读」卡片：音色下拉框**可编辑**——预设 4 个（晓伊/晓晓/云希/云扬），或直接输入任意 edge-tts 音色 ID（如 `ja-JP-NanamiNeural`）。旁边「试听」按钮不依赖"启用朗读"开关，随时合成一句台词对比。存储走 `AppSettings::ttsVoice()`（默认 `zh-CN-XiaoyiNeural`），自定义 ID 会原样保存 |
| 试听没声音 / 语音合成失败 | 现在合成失败会弹提示框（不只是日志）：原因可能是 edge-tts 未安装、没联网、或自定义音色 ID 不存在。用 `azur_agent/Scripts/python.exe -m edge_tts --list-voices` 能看所有合法音色 ID |
| 想跑 TTS 协议级测试（不需要联网/不需要真合成） | `tests/test_tts_client.cpp`：向 `tts_cli.py` 写空 text / 非法 JSON，断言返回合法 JSON 且 `ok=false`。存在 venv 与脚本则跑，否则 `GTEST_SKIP()` |
| 输入框在 AI 回复期间没被禁用，能重复发送 | `mainwindow.cpp` 是靠 `isWaitingResponse_` 控制的，检查 `setInputEnabled(false)` 的调用点 |
| 取消请求后无法再发送新消息 | `mainwindow.cpp` 里 `cancelRequested` 的 lambda，检查 `isWaitingResponse_` 有没有被重置为 `false` |
| Spinner 动画样式想改 | `ui/uiconstants.h`（`kSpinnerFrames` 常量），改这一处全项目生效 |
| 对话历史丢失 / 保存不对 | `conversationmanager.cpp` |
| 路径越权 / 白名单相关的权限问题 | `tool_executor.cpp` 的 `resolveSafePath()` / `s_allowedPaths` |
| Markdown 渲染样式不对（代码块/表格/加粗等） | `markdownrenderer.cpp` |
| 消息气泡样式/头像不对 | `messagebubblewidget.cpp` |
| 打包分发后 AI 人格丢失/变成兜底台词 | `app.qrc` 里的 `<file alias="...">` 有没有和 `promptloader.cpp` 里 `loadFile()` 请求的相对路径（含 `full/`/`lite/` 前缀）完全一致，见「关键设计决策 → 6」 |
| AI 回复占用 token 过多，或消息历史太长导致 API 报错 | `core/contextpolicy.h/.cpp` — 上下文裁剪策略，调整 `maxMessages` / `maxTotalSize` 等参数 |
| 界面重复代码想复用 | 先看 `ui/uiconstants.h` / `data/appsettings.h` / `ui/conversationview.h` / `core/contextpolicy.h` 里有没有现成的 |

- 项目文件树/索引不更新（`project_analyzer.cpp` 的 `needsRebuild()`）
