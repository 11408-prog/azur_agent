## 项目概览

> 这是一款和「企业」（碧蓝航线）聊天的桌面角色扮演助手。

### 目录结构

```
agent_/
├── CMakeLists.txt                  # 构建配置
│
├── core/                           # AI 引擎层
│   ├── ai_client.h/.cpp            # AI API 客户端（流式 + Function Calling）
│   ├── agent_engine.h/.cpp         # Agent 循环引擎（请求 → 流式响应 → 工具调用 → 循环）
│   ├── tool_executor.h/.cpp        # 工具执行器：read_file / list_directory 两个只读工具
│   ├── contextpolicy.h/.cpp        # ★ 上下文裁剪策略（消除重复的 trim 逻辑）
│   ├── promptloader.h/.cpp         # System Prompt 构建器（精简/完整两档人格 + 语气约束指令）
│   └── ttsclient.h/.cpp            # edge-tts 语音合成客户端（QProcess 异步，不阻塞 UI）
│
├── data/                           # 数据持久层
│   ├── conversationmanager.h/.cpp  # 对话管理（创建/保存/加载/删除）
│   └── appsettings.h/.cpp          # ★ 全项目唯一的 QSettings 读写入口
│
├── ui/                             # 通用 UI 组件
│   ├── messagebubblewidget.h/.cpp  # 消息气泡组件（用户/AI 通用）
│   ├── conversationview.h/.cpp     # ★ 对话展示组件（消息列表+输入框+流式节流）
│   ├── markdownrenderer.h/.cpp     # Markdown → HTML 渲染器
│   └── uiconstants.h               # ★ 跨文件共用的 UI 常量（spinner 动画帧）
│
├── chat/                           # 聊天页面（目前是唯一的业务页面）
│   └── chatpagewidget.h/.cpp       # 聊天页面：对话列表 + 发送逻辑 + 步骤指示器
│
├── app/                            # 应用主框架
│   ├── main.cpp                    # 入口：日志钩子 + ElaApplication 初始化
│   ├── mainwindow.h/.cpp           # UI 主框架：导航、AppBar、发送逻辑
│   ├── settingpagewidget.h/.cpp    # 设置页面（UI 控件，实际存储都走 AppSettings）
│   ├── app.qrc                     # Qt 资源文件（prompt 文件的打包兜底）
│   ├── resources/                  # Prompt 资源文件
│   │   ├── full/                   # 完整版（云端模型推荐）：人格 + 台词 + 语气约束指令
│   │   └── lite/                   # 精简版（本地小模型推荐）：人格 + 语气约束指令
│   └── avatar/                     # 头像/背景图片
│
├── tests/                          # 单元测试（Google Test，独立构建为 azur_agent_tests，见「文件详解 → 测试模块」）
│   ├── test_main.cpp               # 自定义 main：先建 QCoreApplication（QProcess 需要）
│   ├── test_tool_executor.cpp      # 路径穿越防护、read_file/list_directory 基础行为
│   ├── test_context_policy.cpp     # 上下文裁剪策略
│   ├── test_appsettings.cpp        # 配置项读写往返
│   ├── test_python_backend.cpp     # Python 工具后端（QProcess 调 cli.py）集成测试
│   ├── test_tts_client.cpp         # TTS 脚本协议级测试（空 text / 非法 JSON，无需联网）
│   └── CMakeLists.txt              # 独立测试目标，FetchContent 拉取 GoogleTest
│
├── python/azur_tools/              # Python 工具后端（可选，默认开启）
│   ├── executor.py                 # 与 core/tool_executor.cpp 等价的纯 stdlib 实现
│   ├── cli.py                      # 工具后端 stdin/stdout JSON 协议入口（C++ 用 QProcess 调它）
│   ├── tts_cli.py                  # edge-tts 语音合成 CLI（同款 stdin/stdout JSON 协议）
│   ├── demo.py                     # 直接在终端跑场景演示
│   └── tests/test_executor.py      # Python 侧单元测试（unittest，无第三方依赖）
│
├── azur_agent/                     # Python 虚拟环境（运行工具后端用，见 .gitignore）
├── lib/ElaWidgetTools/             # ElaWidgetTools 库（需要自行编译，见「构建与运行」）
├── build/                          # 构建输出
└── daily_log/                      # 运行日志
```

标 ★ 的文件（`uiconstants` / `appsettings` / `contextpolicy` / `conversationview`）是为了消除重复代码新增的公共模块，**不属于独立业务逻辑，只被别的模块引用**。


### 技术栈

| 项目 | 内容 |
|------|------|
| 语言 | C++17（工具后端部分用 Python 3，纯标准库） |
| 框架 | Qt 6.5+ (Core / Widgets / Network / Multimedia) |
| UI | ElaWidgetTools（需自行编译，见「构建与运行」） |
| 构建 | CMake 3.19+ |
| AI API | OpenAI Chat Completions 兼容（流式 + Function Calling） |
| 工具后端 | 可选：C++ 原生 / Python（`azur_agent` 虚拟环境 + `python/azur_tools/cli.py`） |
| 语音合成 | edge-tts（微软在线合成，装进 `azur_agent` 虚拟环境；收到回复后朗读 mp3） |
