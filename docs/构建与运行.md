## 六、构建与运行

### 依赖

- Qt 6.5+（Core, Widgets, Network）
- ElaWidgetTools（预编译，位于 `lib/ElaWidgetTools/`）
- CMake 3.19+
- MinGW 或其他 C++17 编译器

### 构建步骤

```bash
mkdir build && cd build
cmake .. -DCMAKE_PREFIX_PATH=/path/to/Qt6
cmake --build .
```

### 调试日志

所有 `qDebug()` 输出重定向到：
```
agent_/daily_log/azur_debug_YYYY-MM-DD.log
```
