## 构建与运行

### 依赖

- Qt 6.5+（Core, Widgets, Network）
- ElaWidgetTools（ 没有预编译，如果使用的话需要编译一下并将生成物创建一个`lib/`文件夹并放入,如果不确定位置可以看CMakeList）
- CMake 3.19+
- MinGW 或其他 C++17 编译器

### 构建步骤
如果有条件使用ide如qt creator会更轻松<br>
```bash
mkdir build && cd build
cmake .. -DCMAKE_PREFIX_PATH=/path/to/Qt6
cmake --build .
```

### 调试日志

所有 `qDebug()` 输出重定向到：
```
agent_/daily_log/azur_debug_YYYY-MM-DD.log
```
