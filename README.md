# Azur Agent 项目说明

> 基于 Qt6 + ElaWidgetTools 构建的 AI 角色扮演聊天软件。提示词是使用碧蓝航线的企业的台词构建的。目前支持日常聊天和简单的代码生成以及工具调用。目前还在开发阶段。
