三、第一阶段：文件操作能力
================================


优先级：★★★★★


目标：

让 AI 从“查看代码”变成“修改项目”。


新增工具：


--------------------------------
1. write_file
--------------------------------


作用：

创建文件或者完整修改文件。


例如：


AI：

我要修改 mainwindow.cpp


调用：

write_file

参数：

path:
mainwindow.cpp

content:
修改后的代码



--------------------------------
2. apply_patch
--------------------------------


这是最重要的功能。


不要直接覆盖整个文件。

采用 Patch。


例如：


修改前：

void test()
{

}


修改后：

void test()
{

    hello();

}



优势：

- 修改范围小
- 不容易破坏代码
- 支持人工审核
- 接近 Codex 工作方式



--------------------------------
3. 修改确认系统
--------------------------------


修改前显示：


文件：

mainwindow.cpp


变化：

+ 新增代码

- 删除代码



按钮：

[接受修改]

[拒绝修改]

推荐结构：


Azur Agent
